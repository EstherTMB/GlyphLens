# GlyphLens (v1.0)

Современный, лёгкий и полностью лишённый рекламы и трекеров оверлей-помощник («оптическая линза») для тренировки памяти и ввода глифов в **Ingress Prime**.

## Главные особенности
- **Работает на всех Android (от Android 5.0 до Android 15/16)**: использует актуальный `TYPE_APPLICATION_OVERLAY` и безопасный порог прозрачности, чтобы защита Android 12+ от Tapjacking не блокировала сквозные нажатия в игру.
- **Умный поплавок с индикацией режима**:
  - В **фиксированном режиме** на плавающем кружке горит выбранная цифра (`1`..`5`), и по нажатию сразу открывается холст на это число глифов.
  - В **динамическом режиме (`?`)** на кружке горит знак вопроса: при нажатии на него перед взломом выскакивает быстрый ряд кнопок `[1][2][3][4][5]`, позволяющий за долю секунды выбрать количество глифов под уровень конкретного портала.
- **Собственная векторная иконка**: чёткий гексагон Шейперов внутри оптической линзы (`ic_launcher.xml`).
- **Калибровка под современные экраны 20:9**: ползунки размера квадрата и вертикального сдвига позволяют совместить 11 точек оверлея один-в-один с гексагоном в Ingress Prime.

## Как собрать APK в облаке GitHub (без установки Android Studio)
1. Создайте новый репозиторий на GitHub (например, `GlyphLens`).
2. Загрузите в него содержимое этого архива (включая папку `.github/workflows/build.yml`).
3. Перейдите во вкладку **Actions** вашего репозитория — сборка запустится автоматически и через ~1.5 минуты выдаст готовый файл `GlyphLens-debug-apk`.
